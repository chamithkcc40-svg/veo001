# Production plan - doppler-effect-redshift (Remotion)

## Format
- 1920x1080, 16:9, 30 fps, YouTube. Title-safe margin 5% (96 px left/right, 54 px top/bottom).
- Captions live in the bottom 18% band (y 860-1026); labels lower-left third; centre kept for wave action.
- Last 12 s keep upper-left / upper-right sky clear for end-screen elements.
- Duration set by the voiceover: part_01 (79.31 s) + part_02 (106.37 s) concatenated with no gap = 185.68 s, plus a short head (0.5 s silence before "Listen.", per 08 §4) and an end-screen tail.

## Architecture
- `data/video.json`: generated by `scripts/build_timing.py` from the word timings of the real audio (sentences, chapters, words, scene starts/ends, SFX cue frames). Every component reads frames from it; no magic numbers.
- `src/theme.ts`: palette, easings, springs, fonts (from STYLE_BIBLE.md).
- `src/kit/`: rigs (Pip, Nell, Skipper, Doppler, BuysBallot, HornPlayer, Slipher, Hubble, Lemaitre) built on one shared jointed `Rig` system; props; environment layers; Rings engine (physically correct emission: each ring centred where the source was when emitted, constant radius speed); info-visuals (Timeline, Barcode, HubbleChart, SkyMap, Speedometer, TickBar); effects (Grain, Vignette, Grade, LightLeak, DepthBlur, Particles); Captions.
- `src/chapters/ChN.tsx`: each chapter is a component that takes the global frame offset; scenes are `<Sequence>`s inside.
- Chapters run on the GLOBAL frame timeline (`Full` just stacks the chapter Sequences at their start frames), so per-chapter renders + concat equal the Full render.
- Audio: one offline mix `public/audio/mix.wav` (Python + ffmpeg): VO, synthesized ambience beds, SFX (supplied library + synthesized foley) at cue frames, a synthesized 90 BPM score with sidechain-style ducking, loudnorm once to -14 LUFS / -1 dBTP. Per-chapter compositions play the matching slice of the same mix via `startFrom`.

## Long-video rendering and joining (done by the user locally, never here)
- Render each chapter composition to `out/chN.mp4` (h264, crf 16, same encoder settings), then join with the ffmpeg concat demuxer and `-c copy` (README-LOCAL.md). Or render `Full` in one go.
- Chapter boundaries fall on whole frames, audio is the same mix sliced at those frames, so the join is gapless.

## Quality gates
1. `npx tsc --noEmit` clean.
2. Asset audit script: every `staticFile()` path exists; every file in public/ is referenced.
3. Stills via `scripts/stills.mjs` (bundles once, renders many frames, concurrency 1): five moments per scene -> contact sheets, compared with reference frames.
4. Motion check: pairs of low-res stills 8 frames apart at >= 24 sample points per chapter; mean abs luminance diff > 1.5 on 270x480-equivalent downscale counts as moving; target >= 90% of the reference share.
5. Caption sync: caption page times derive from word timings; spot-check frames on sentence boundaries; safe-area box check.
6. Audio: cue list vs. frames, loudness via ffmpeg ebur128 (target -14 LUFS integrated, TP <= -1 dBTP), no clipping.
7. Scores 1-10 per chapter on the 9 criteria; every score >= 8 or logged under Gaps.
